# Python Projects
A collection of small, focused tools built in Python.
Each project lives in its own folder with its own README and requirements.

## Included Projects
### 🕷️ Costco Webscraper
Automates product availability checks using Selenium + undetected‑chromedriver.
Features human‑like behavior, notifications, logging, and a simple GUI.

## 📜 Loot List Manager
Desktop companion app for the LootListManager WoW addon.
Syncs Google Sheets ↔ SavedVariables with a CustomTkinter interface.

## 🌐 Network Automation Tools
Utility scripts for interacting with network devices.
Useful for configuration, testing, and repeatable automation tasks.

Each project contains:

- Its own README

- Its own requirements.txt

- Its own entry point
